# 구조
## Decoder-only (GPT 계열) — 텍스트 생성이 목적이라.
```
입력 토큰 임베딩
    |
[Layer 1]
    ├── LayerNorm
    ├── Self-Attention (causal)  ← 핵심
    ├── LayerNorm
    └── FFN (Feed-Forward Network)
    |
[Layer 2]
    ├── 같은 구조 반복
    ...
[Layer N]
    |
LayerNorm
    |
출력 head (vocab_size 크기 linear) → 다음 토큰 확률
```



다만, 설계에 있어서 순수 성능보다는 비용과 성능 모두를 생각함 > GPU 섬유 이슈
